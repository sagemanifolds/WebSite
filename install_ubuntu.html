Installing SageMath 10.10 in Ubuntu 24.04 or 26.04

There is no Ubuntu system package for SageMath in Ubuntu 24.04 or 26.04. Fortunately, it easy to install it with just a few shell commands typed in a terminal, thanks to the Conda package/environment manager:

Step 1: install Conda via Miniforge

Either download Miniforge installer from here or run in a terminal

curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"

Then run the installer via

bash Miniforge3-$(uname)-$(uname -m).sh

Answer yes to the question Proceed with initialization?
Close the terminal and reopen a new one to activate Conda (in the "base" environment).

Step 2: create a new conda environment containing SageMath

Run the command

conda create -n sage sage python=3.13

This will download SageMath from the conda-forge repository and install it into a Conda environment named sage.

Step 3: run SageMath

Activate the Conda environment sage:

conda activate sage

and run SageMath in a Jupyterlab notebook by typing

sage -n jupyterlab

Alternatively, you may also run SageMath in a classic Jupyter notebook via sage -n. You may also run it in console mode by typing simply sage.

That's it!
NB: next time you want to run SageMath on your computer, only Step 3 is necessary.
For more details, see he Install from conda-forge section of the SageMath Installation Manual.
